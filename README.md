# DocClarify-RAG-Based-Document-Question-Answering-System

DocClarify is a Retrieval-Augmented Generation (RAG) based document question-answering system that allows users to upload PDF, DOCX, and TXT files and ask questions based on their content. The application uses local text processing, Sentence Transformer embeddings, and ChromaDB for semantic retrieval, while Gemini API generates grounded answers from the retrieved context. It also supports source citations, PDF page references, chat history, follow-up questions, and document management.
